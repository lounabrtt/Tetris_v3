#Tetris Game

#A Tetris developed in C# using WPF for the graphical interface.

    Features:

Dynamic Grid: The game grid is rendered dynamically using Canvas and Image elements.
Block Mechanics:
Supports movement (left, right, down) and hard drop.
Includes block rotation (clockwise and counterclockwise).
Features ghost blocks to preview the landing position.
Allows holding and swapping blocks.
Scoring System: Tracks and displays the player's score in real time.
Game Over Menu: Shows final score with an option to play again.

    Controls

Arrow Keys: 
Left/Right: Move the block left/right.
Down: Move the block down faster.
Up: Rotate the block clockwise.
Z: Rotate the block counterclockwise.
C: Hold or swap the current block.
Space: Perform a hard drop.
